1. التقاط كل شيء محلياً (بما في ذلك أوامر الحذف):
هذا الأمر يخبر Git أن يسجل كل الملفات الجديدة، ويسجل أيضاً "حذف" أي ملف قمت أنت بمسحه محلياً.

Bash
git add -A
2. توثيق هذه الحالة النهائية:

Bash
git commit -m "refactor: force sync remote repository with absolute local state"
3. الضربة القاضية (الرفع الإجباري - Force Push):
حرف الـ -f هنا هو اختصار لـ --force. وهو أمر حاسم يخبر GitHub: "امسح أي تاريخ أو ملفات تتعارض مع نسختي، واجعل المستودع نسخة طبق الأصل (Mirror) مما أرفعه لك الآن".

Bash
git push -f origin main
